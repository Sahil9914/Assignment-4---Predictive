# Assignment-4---Predictive

# Learning Probability Density Functions Using GANs

# Overview

This project focuses on learning the unknown Probability Density Function (PDF) of a transformed random variable using a Generative Adversarial Network (GAN). The model is trained purely on data samples without assuming any parametric form (like Gaussian or Exponential) for the underlying distribution.

# Dataset

The project uses India Air Quality data, specifically focusing on NO₂ concentration as the primary feature (x).

Data Source: [India Air Quality Dataset](https://www.kaggle.com/datasets/shrutibhargava94/india-air-quality-data)

Feature: no2 (nitrogen dioxide).

# Step 2: GAN Architecture & PDF Estimation

A GAN was designed and trained to learn the distribution of the transformed variable z.

Generator: Implicitly models the probability density of $z$ by mapping latent noise $N(0, 1)$ to the data space.

Discriminator: Learns to distinguish between real samples from $z$ and fake samples generated by the network.

# Step 3: PDF Approximation

After training the GAN for 4000 epochs, a large number of samples were generated to estimate the final probability density using Kernel Density Estimation (KDE).
